隐私政策

HTML浏览器 (HTML Browser) · 最后更新：2026 年 4 月 21 日

一句话总结：我们不收集您的任何数据。
HTML浏览器是一款纯本地运行的 HTML 文件阅读器，所有文件存储在您的设备上，不上传至任何服务器。

1. 数据收集

我们不收集任何数据。具体而言：

  • ❌ 不收集任何个人信息（姓名、邮箱、电话、地址等）
  • ❌ 不进行使用行为分析或追踪
  • ❌ 不发送崩溃报告至外部服务器
  • ❌ 不使用 Cookie 或网络追踪技术
  • ❌ 不包含广告或广告标识符（IDFA）
  • ❌ 不使用任何收集数据的第三方 SDK
  • ❌ 不访问通讯录、相册、位置、麦克风、相机等系统权限

2. 数据存储

  • 您导入的所有 HTML 文件均仅存储在您设备本地（App 沙盒内）
  • 文件元数据（名称、导入时间、标签等）以 JSON 格式存储在本地
  • 缩略图预览在本地生成和缓存
  • 界面语言偏好、外观模式等设置存储在本地（UserDefaults）
  • 没有任何数据会传输至任何服务器

3. 网络访问

本应用程序本身不发起任何网络请求。

仅在以下情况下，您的设备可能产生网络流量：

  • 当您导入的 HTML 文件本身引用了外部资源（如 Google Fonts、CDN 托管的 JavaScript 库）时，WKWebView 会加载这些资源
  • 这些网络请求由 HTML 内容本身发起，而非应用程序
  • App 已内置 9 个主流 JavaScript/CSS 库（Chart.js、ECharts 等），优先使用本地版本，减少联网需求

4. 文件访问

  • 应用仅访问您明确导入的文件
  • 导入的文件会被复制到 App 的私有存储区
  • App 无法访问沙盒外的任何文件
  • App 不访问您的 iCloud Drive、照片、联系人等

5. 第三方服务

本应用不使用任何第三方服务、分析工具或 SDK。

唯一与苹果交互的部分是：

  • Apple StoreKit：用于处理 App 内自愿打赏（如果您选择使用）。该功能由 Apple 管理，受 Apple 隐私政策约束。

6. App 内购买

App 提供 4 档自愿打赏商品，用于支持开发者。

  • 所有购买通过 Apple StoreKit 处理
  • App 本地仅记录您的打赏总次数（一个计数器），不关联任何身份信息
  • 该计数仅用于 App 内显示"感谢您的 N 次支持"，不上传任何服务器
  • 所有 App 功能完全免费，打赏不解锁任何功能

7. 儿童隐私

本应用不向任何人收集数据，包括 13 岁以下儿童。本应用年龄评级为 4+。

8. 政策变更

如本政策有任何更新，我们将在本页面发布最新版本，并更新顶部的"最后更新"日期。重大变更将在 App 内通过更新说明告知。

Privacy Policy

HTML Browser · Last Updated: April 21, 2026

In one sentence: We do not collect any of your data.
HTML Browser is a local-only HTML file viewer. All files are stored on your device and never uploaded to any server.

1. Data Collection

We do not collect any data. Specifically:

  • ❌ No personal information collected (name, email, phone, address, etc.)
  • ❌ No usage analytics or tracking
  • ❌ No crash reports sent to external servers
  • ❌ No cookies or web tracking technology
  • ❌ No advertising or IDFA
  • ❌ No third-party SDKs that collect data
  • ❌ No access to Contacts, Photos, Location, Microphone, Camera, etc.

2. Data Storage

  • All HTML files you import are stored only on your device (inside the app's sandbox)
  • File metadata (names, import dates, tags) is stored locally in JSON format
  • Thumbnail previews are generated and cached locally
  • UI language preference, appearance mode, and other settings are stored locally (UserDefaults)
  • No data is ever transmitted to any server

3. Network Access

The app itself makes zero network requests.

Network traffic only occurs when:

  • HTML files you import reference external resources (Google Fonts, CDN-hosted JavaScript libraries), in which case WKWebView loads them
  • These requests are made by the HTML content itself, not by the app
  • 9 popular JavaScript/CSS libraries (Chart.js, ECharts, etc.) are pre-bundled locally to reduce the need for network access

4. File Access

  • The app only accesses files you explicitly import
  • Imported files are copied to the app's private storage
  • The app cannot access any files outside its sandbox
  • The app does not access iCloud Drive, Photos, Contacts, etc.

5. Third-Party Services

The app uses no third-party services, analytics, or SDKs.

The only interaction with Apple is:

  • Apple StoreKit: For processing optional in-app tips (if you choose to use them). This is managed by Apple and governed by Apple's privacy policy.

6. In-App Purchases

The app offers 4 tiers of optional tips to support the developer.

  • All purchases are processed through Apple StoreKit
  • The app only locally records your total tip count (a simple counter), not linked to any identity
  • This counter is only used to display "Thank you for your N tips" inside the app and is not uploaded anywhere
  • All app features are completely free; tips do not unlock any features

7. Children's Privacy

The app does not collect data from anyone, including children under 13. The app is rated 4+.

8. Policy Changes

If this policy is updated, we will publish the new version on this page and update the "Last Updated" date at the top. Major changes will be announced via the app's release notes.
