❓ 常见问题

如何把 HTML 文件导入到 App 里？

HTML Reader 支持多种导入方式：

  • 打开 App → 点右上角 "+" → 从"文件"、iCloud、本机存储选择 HTML 文件
  • 在 微信、AirDrop、邮件 等 App 中，长按 HTML 文件 → "用其他 App 打开" → 选择 HTML Reader
  • 在 Safari 下载 HTML 后，用"分享"按钮发送到 HTML Reader
为什么我的 HTML 文件打开后图表不显示？

图表加载失败通常有两种原因：

  • 引用的 CDN 库 HTML Reader 没有内置 — 目前内置了 Chart.js、ECharts、html2canvas、jsPDF、Mermaid、Marked、Highlight.js、SheetJS、Tabler Icons 共 9 个主流库。其他 CDN 库在离线时无法加载。
  • HTML 文件本身有错误 — 建议先在电脑浏览器里确认文件能正常渲染，再导入手机。

如遇到具体库需求，欢迎邮件告诉我，后续版本可能会内置。

我的 HTML 文件是否会上传到服务器？

不会。HTML Reader 是纯本地运行的 App：

  • 所有 HTML 文件仅存储在您设备的 App 沙盒内
  • App 本身不发起任何网络请求
  • 只有当 HTML 文件本身引用了外部资源（如 Google Fonts、CDN 库），WebView 才会去加载那些资源

详见 隐私政策。

打赏会解锁什么功能吗？

不会。所有功能完全免费。

打赏是完全自愿的，如果您觉得 App 好用、想支持独立开发者继续维护更新，可以在 App 里选择一档打赏金额。不打赏也不影响任何功能使用。

如何删除已导入的 HTML 文件？

在文件列表中：

  • 列表视图：向左滑动文件 → 点"删除"
  • 网格视图：长按文件 → 选择"删除"
  • 或点右上角编辑按钮 → 批量选择删除

删除后无法恢复，请谨慎操作。

支持在哪些设备上使用？

HTML Reader 支持：

  • iPhone（iOS 16.0 及以上）
  • iPad（iPadOS 16.0 及以上）
  • 搭载 Apple Silicon（M1 及以上）的 Mac（通过"iPhone 和 iPad App"方式运行）

❓ Frequently Asked Questions

How do I import HTML files into the app?

HTML Reader supports multiple import methods:

  • Open the app → tap "+" in the top-right → select HTML files from Files, iCloud, or local storage
  • In apps like Messages, AirDrop, Mail, long-press an HTML file → "Open in another app" → choose HTML Reader
  • After downloading HTML in Safari, use the Share button to send it to HTML Reader
Why don't charts display in some of my HTML files?

Chart loading failures usually have two causes:

  • The referenced CDN library isn't bundled with HTML Reader — We pre-bundle 9 popular libraries: Chart.js, ECharts, html2canvas, jsPDF, Mermaid, Marked, Highlight.js, SheetJS, and Tabler Icons. Other CDN libraries cannot load when offline.
  • The HTML file itself has errors — We recommend verifying the file renders correctly in a desktop browser before importing.

If you have a specific library need, let me know — future versions may bundle it.

Are my HTML files uploaded to a server?

No. HTML Reader runs entirely locally:

  • All HTML files are stored only inside the app's sandbox on your device
  • The app itself makes zero network requests
  • Network traffic only occurs when an HTML file itself references external resources (like Google Fonts or CDN libraries); WebView loads them on demand

See the Privacy Policy for full details.

Do tips unlock any features?

No. All features are completely free.

Tips are entirely voluntary. If you find the app useful and want to support indie development, you can choose a tip tier inside the app. Not tipping has zero impact on your experience.

How do I delete imported HTML files?

In the file list:

  • List view: swipe left on a file → tap "Delete"
  • Grid view: long-press a file → select "Delete"
  • Or tap the edit button in the top-right to delete multiple at once

Deletion cannot be undone — please confirm before deleting.

Which devices are supported?

HTML Reader supports:

  • iPhone (iOS 16.0 and above)
  • iPad (iPadOS 16.0 and above)
  • Mac with Apple Silicon (M1 and later) via "iPhone and iPad Apps" mode
